# Pink Baby

Next.js storefront for Pink Baby feeding and care essentials.

## Preview

```bash
npm ci
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

Production-style local run:

```bash
npm run build
# Prefer the standalone server (matches Docker):
node .next/standalone/server.js
# After copying static assets as the Dockerfile does, or use:
npm run start
```

See `HANDOFF.md` for versions, security notes, Coolify steps, and pending integrations.
